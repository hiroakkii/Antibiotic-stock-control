# 在宅 抗菌薬・解熱鎮痛薬 在庫管理

患者宅に置いている抗菌薬・解熱鎮痛薬の在庫を管理するアプリです。
処方日からの経過を色で示し、在庫薬の使用開始指示が出たときに Dr 用の処方メモを発行します。

インストールは不要です。`index.html` をブラウザ（Microsoft Edge / Google Chrome）で開くと使えます。
インターネットに接続していない端末でも動きます。

## 主な機能

| 画面 | できること |
| --- | --- |
| お守り薬一覧 | 患者ごとのお守り薬を表示。処方日からの経過期間、黄色・赤色に変わる日を表示。赤 → 黄 → 期限内 の順に並びます |
| お守り薬登録 | 患者・処方日・処方医を入れ、薬剤を1種類ずつ入力します。「＋ 薬剤を追加」で同時に処方された複数の薬剤をまとめて登録できます（薬剤ごとに別のお守り薬として管理されます）。薬剤名を入力すると薬剤マスタから候補が出て、区分・有効期限・単位が自動で入ります |
| 使用開始指示 | お守り薬一覧の「使用開始指示」（**抗菌薬のみ**表示されます）から、使用開始日・開始指示医師などを入力し、処方メモを発行します。処方メモが未発行の間は、お守り薬一覧に「メモ未発行」として残り（一覧の上部に表示）、「処方メモ発行」ボタンから発行できます。発行済みになると一覧から消えます。入力を間違えた場合は、同じ行の「使用開始を編集」で直すか、「使用開始を取り消す」で使用記録ごと取り消してお守り薬を一覧に戻せます（「使用済・廃棄も表示」にした使用済の行からも取り消せます） |
| 使用記録（データシート） | 患者名・使用開始日・医師名・処方メモ発行の有無を一覧表示。未発行の絞り込み、再印刷、Excel 出力ができます |
| 患者マスタ | Excelの患者マスタを読み込みます。お守り薬登録の患者名入力で候補が出て、選ぶと患者IDも自動で入ります（カナでも検索可） |
| 薬剤マスタ | Excel の薬剤マスタを読み込みます。画面上での追加・修正もできます |
| 設定・バックアップ | 施設名・メモの表題と依頼文・医師名リストの設定、データのバックアップと復元 |

## 色の判定

### 製造からの有効期限で判定（標準）

薬剤マスタの有効期限（製造から）を使い、**処方日**から数えて判定します。

- **黄色**: 処方日 + 有効期限の半分 の日から
- **赤色**: 処方日 + 有効期限 の日から

例: 2026/10/29 処方・有効期限 2 年 → 2027/10/29 から黄色、2028/10/29 から赤色。

有効期限が奇数月（例: 1年5ヶ月）の場合、黄色の日は処方日から赤色の日までの日数の半分（端数切り上げ）で計算します。
月末日の処方（例: 2/29）で該当日が無い月は、その月の末日になります。

### 実際の使用期限で判定（薬局等で確認できた場合）

お守り薬登録の「実際の使用期限（任意）」に年月を入力すると、製造からの期限より優先して判定します。
医薬品の期限は「2027年10月まで」のように月までの表記なので、**その月の末日まで有効**として扱います。

- **黄色**: 期限まで1年未満になった日から（例: 2027年10月まで → 2026/11/01 から）
- **赤色**: 期限を超えた日から（例: 2027年10月まで → 2027/11/01 から）

## 処方医の登録

「設定・バックアップ」画面の「処方医の登録」で医師名を登録しておくと、お守り薬登録の「処方医」と使用開始指示の「開始指示医師」の入力候補になります。

## 薬剤マスタ（Excel）

### 医薬品マスタ（内用薬・外用薬）: `master/医薬品マスタ_内用外用.xlsx`

薬価基準収載の内用薬 7,073 件・外用薬 1,862 件をまとめたファイルです。「薬剤マスタ」画面から読み込みます。

| シート | 内容 |
| --- | --- |
| 検索 | ① 医薬品名 → 薬効分類名　② 薬効分類名/コードのキーワード検索　③ 薬効分類コード（3桁）→ 該当医薬品の一覧 |
| 薬効分類マスタ | 薬効分類コード・名称・件数。**黄色の「対象区分」「有効期限(年)」列がアプリ用の設定欄** |
| 医薬品マスタ | 全医薬品。薬効分類・対象区分・有効期限が自動で付き、オートフィルタで絞り込めます |

- 薬効分類コードは薬価基準収載医薬品コードの左3桁です。
- 「薬効分類マスタ」の「対象区分」に `抗菌薬` / `解熱鎮痛薬` / `麻薬` を入れた分類の医薬品だけがアプリに取り込まれます（空欄の分類は取り込まれません）。
- 初期設定は 抗菌薬: 611〜615・619・621・624、解熱鎮痛薬: 114、麻薬: 811・821 です。**有効期限(年)は仮の3年**なので、必ず実際の値に直してください。
- 個別の医薬品だけ有効期限を変える場合は、「医薬品マスタ」の「個別設定(年)」に入力します。
- 設定を変えたら Excel で保存し、アプリの「薬剤マスタ」画面で読み込み直してください。
- 薬名は読み込み時に全角英数が半角になります（`カロナール錠２００` → `カロナール錠200`）。

作り直す場合: `python3 tools/build_master.py <内用薬.xlsx> <外用薬.xlsx> <薬効分類マスタを含むブック.xlsx> <出力.xlsx>`（出力後に LibreOffice/Excel で開いて保存すると計算結果が入ります）。

### 有効期限の確認（未確認の薬剤への警告）

薬剤マスタの有効期限は仮の値のため、薬剤ごとに「確認済み」にするまで未確認として扱います。

- お守り薬登録で未確認の薬剤を選ぶと、薬剤の欄に警告と「薬剤マスタで確認する」リンクが出ます。リンクを押すと、その薬剤を検索した状態で薬剤マスタが開きます。
- 実際の有効期限を確認し（必要なら「編集」で有効期限を直し）、「確認済みにする」を押すと、次回から警告は出ません。誤って押した場合は「未確認に戻す」で戻せます。
- 未確認のまま保存しようとすると、確認のメッセージが出ます（そのまま登録も可能です）。
- 薬剤マスタの画面では、薬剤名・コードで検索でき、「有効期限が未確認のものだけ」に絞り込めます。
- Excelの薬剤マスタを読み込み直しても、同じ薬剤名で有効期限が同じなら確認済みの印は引き継がれます。

### 簡易な薬剤マスタ

1 行目を見出し行にしてください。列の順番は自由です。ひな形は「薬剤マスタ」画面からダウンロードできます。
サンプル: [`sample/薬剤マスタ_サンプル.xlsx`](sample/薬剤マスタ_サンプル.xlsx)（有効期限は仮の値です）

| 列名 | 必須 | 内容 |
| --- | --- | --- |
| 区分（または対象区分） | ○ | `抗菌薬`・`解熱鎮痛薬`・`麻薬` のいずれか |
| 薬剤名（または品名） | ○ | 入力補助の候補として表示される名前 |
| 有効期限(年) / 有効期限(月) | どちらか○ | 製造からの有効期間。両方ある場合は合算 |
| コード・規格・単位・用法用量 | | あれば取り込みます。用法用量は使用開始指示の初期値になります |

## 処方メモ

使用開始指示を保存すると処方メモが表示され、「印刷する」で印刷できます。印刷後に確認すると、使用記録の「処方メモ」が **発行済** になります。

メモの項目は 患者名・使用開始日・開始指示医師・指示内容・指示記入日です。指示内容と指示記入日は医師が記入する空欄です（前回の処方内容は反映しません）。表題は「設定」で変更できます（初期値: 処方メモ（お守り薬））。処方メモのフォントは BIZ UDPゴシック（Windows 10 以降に標準搭載。無い端末では游ゴシック等で代替）です。

「使用記録」画面の「Excelに出力」で、`患者名 / 使用開始日 / 医師名 / 処方メモ発行` を先頭列にしたデータシートを出力できます。

## データの保存について

- データは、使っているパソコンのブラウザ内（localStorage）に保存されます。別のパソコンやブラウザとは共有されません。
- ブラウザの閲覧履歴データを削除すると消える場合があります。「設定・バックアップ」から定期的にバックアップ（JSON）を保存してください。
